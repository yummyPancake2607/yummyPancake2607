# 🏰 The Great Hall — Things I've Built

Some of the projects currently occupying my workshop.

### 🧙 CRISPERHOST

**A self-hosted Platform-as-a-Service designed around simple deployment.**

Instead of making developers fight with complicated deployment workflows:

```text
Code → One Click → Docker → Deployed
```

**Spell components:**
`FastAPI` `React` `SQLite` `SQLAlchemy` `Docker`

---

### 📰 TechPulse

A technology news platform that gathers and presents the latest tech stories
through automated feeds.

**Spell components:**
`React` `Node.js` `RSS`

---

### 🦉 OwlLock

A Linux desktop security experiment built around facial recognition.

Because apparently a password wasn't magical enough.

**Spell components:**
`Python` `OpenCV` `face_recognition` `PyQt`

---

### ⚗️ Offline Converter

A Flutter application designed to perform media and file conversion **locally**,
without relying on cloud services.

The interesting part?

The conversion engine is written in **C++** and connected to Flutter through **FFI**.

```text
Flutter
   │
   ▼
   FFI
   │
   ▼
 C++
   │
   ▼
 FFmpeg
```
